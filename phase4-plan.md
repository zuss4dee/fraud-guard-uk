# Phase 4: Official PDF Report Generation

## Objective
Generate professional PDF compliance reports that landlords can use for Right to Rent documentation and record-keeping.

## Implementation Steps

### Step 1: Install Dependencies
```bash
npm install html2canvas jspdf
```

### Step 2: Create the Report Component (`src/components/reports/compliance-report.tsx`)
- **Styling:** Formal legal document appearance (A4 proportions)
  - Background: Always White (`bg-white`)
  - Text: Always Black (`text-slate-900`)
  - Header: "FRAUDGUARD UK - DOCUMENT FORENSIC REPORT"
  - Layout: Two columns (Risk Score | Document Details)
  - Verdict Stamp: Visual badge (VERIFIED/HIGH RISK/SUSPICIOUS)
  - Footer: Generated by info + Compliance Reference ID

### Step 3: Update Scan Page (`src/app/scan/page.tsx`)
- Import `ComplianceReport` component
- Place in hidden div (`absolute left-[-9999px]`) for PDF capture
- Add "Download Official Report" button with Download icon
- Use `html2canvas` to capture report, `jspdf` to save as PDF

### Step 4: PDF Naming Convention
- Format: `FraudGuard_Report_YYYY-MM-DD.pdf`
- Example: `FraudGuard_Report_2026-01-24.pdf`

## Report Contents
1. **Header:** FraudGuard UK branding + Report Reference ID
2. **Risk Assessment:** Large risk score display (0-100)
3. **Document Details:** File name, scan date, scan time
4. **Verdict Stamp:** Color-coded badge (Green/Amber/Red)
5. **Analysis Summary:** AI-generated findings
6. **Issues List:** Detailed flags with icons
7. **Compliance Notice:** UK Right to Rent disclaimer
8. **Footer:** Generation timestamp + reference ID

## Acceptance Criteria
- [x] PDF downloads with correct filename format
- [x] Report displays all analysis data
- [x] Verdict stamp is color-coded
- [x] Report maintains A4 proportions
- [x] Professional, print-ready appearance
